## 3. Projects Portfolio

### 1. Plant Brain — AI Platform for Industrial Knowledge Intelligence
* **Type**: Hackathon → Production | Event: ET Techathon 2026 (Team Joyboy) | Status: Live deployed
* **Description**: Industrial facilities drown in unstructured documentation — manuals, compliance reports, maintenance logs, SOPs. Engineers waste hours hunting for answers scattered across dozens of PDFs. Plant Brain converts document chaos into a queryable, intelligent knowledge system with 3 specialized AI agents.
* **Core Innovation — Hybrid Graph-RAG**: Fuses a NetworkX knowledge graph (traversal-based) with ChromaDB vector search. The graph anchors entity-specific lookups while the vector layer handles semantic context, delivering 3–5× higher retrieval precision over standard RAG on entity-anchored industrial queries.
* **Three Specialized AI Agents**:
  1. *Expert Copilot*: General Q&A across all ingested documents.
  2. *Maintenance RCA*: Root cause analysis for equipment failures, tracing failure chains through the knowledge graph.
  3. *Compliance Analyzer*: Real-time gap detection between current practices and regulatory standards.
* **Tech Stack**: React 18, TypeScript, Vite, FastAPI (Python 3.12), ChromaDB, NetworkX, spaCy NER, ONNX Runtime (all-MiniLM-L6-v2), Azure AI Foundry GPT-5 Mini, Docker, GitHub Actions CI/CD, Azure App Service, Vercel CDN.
* **Scale & Metrics**: 19 documents → 161 graph nodes + 464 auto-generated relationships. Information retrieval time dropped from 23 minutes to 3 seconds (99.6% reduction).

* **Metrics**: 89% accuracy on APTOS 2019 dataset; benchmarked cross-dataset generalization at 83% accuracy on 50,000+ EyePACS images without retraining.
